Кто мы

Mox Tools — это независимая студия, основанная энтузиастами. Днем мы пишем утилиты, чтобы сделать разработку игр удобнее, а вечером — используем эти же инструменты для создания собственных игровых миров.

Мы верим, что хороший инструмент должен быть незаметным, а хорошая игра — затягивать с первых минут. Никаких корпоративных рамок, только чистый код и страсть к своему делу.

Наш стек

Игры

Unity, C#, собственные шейдеры. Мы фокусируемся на 2D-платформерах и атмосферных нарративных проектах.

Утилиты

Python для бэкенда, PyQt6 для десктопных редакторов, чистый JavaScript для веб-инструментов.

Сайт

Чистый HTML5, CSS3 и Vanilla JS. Никакого лишнего веса — сайт должен летать даже на старых смартфонах.
