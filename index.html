Кто я

Mox Tools — это мой личный проект. Меня зовут Савва, и я занимаюсь разработкой на языке C. Здесь нет корпоративных рамок и огромных команд — только чистый код, микроконтроллеры, системное программирование и создание нативных приложений.

Я верю, что C — это фундамент, а GCC — лучший компилятор. Все мои инструменты создаются с упором на производительность и минимальный размер.

Мой стек

Язык и сборка

Чистый C (C99/C11). Основной инструмент — GCC (GNU Compiler Collection). Для сборки кроссплатформенных проектов использую Make.

Мобильные утилиты

Для создания APK-пакетов под Android я разработал собственный инструмент — MCAPKB (Mox C APK Builder). Он позволяет собирать нативные приложения на C без тяжеловесных IDE.

Сайт

Чистый HTML5, CSS3 и Vanilla JS. Сайт работает как статика на GitHub Pages, чтобы не отвлекать ресурсы от основной разработки.
